# Html Forms Using Tailwind CSS

Welcome to **vhbuyio's open-source form collection** 🚀

This repository contains a collection of responsive and modern HTML forms built using **Tailwind CSS**. Anyone can contribute and showcase their work here.

## 📌 Who can contribute?

* Developers
* Students
* Interns (including paid training interns)
* Open-source contributors

## 🎯 उद्देश्य (Purpose)

To create a centralized collection of high-quality Tailwind CSS forms that can be reused in real-world projects.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS

## 📂 Contribution Guidelines

1. Fork the repository
2. Create a new folder with your name or form type
3. Add your HTML file inside the folder
4. Ensure your form is responsive and clean
5. Submit a Pull Request

## 📋 Rules

* Use only Tailwind CSS for styling
* Keep code clean and readable
* Do not upload duplicate forms
* Add a short description of your form

## 🌟 Benefits

* Showcase your work publicly
* Build your portfolio
* Gain real open-source contribution experience
